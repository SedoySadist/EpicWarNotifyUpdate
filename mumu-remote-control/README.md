# MuMu Remote

Отдельное Android-приложение для управления MuMu Bot с телефона.

## Что уже есть в первой версии

- список всех подключённых MuMu;
- имя аккаунта, foreground-приложение и ресурсы из `bot_runtime.json`;
- отображение активной задачи, когда её можно определить из `bot_state.json`;
- пауза любого аккаунта на **любое число минут** от 1 до 1440;
- безопасная пауза: текущая задача не рубится посередине — после завершения DeviceActionLock игра закрывается;
- досрочное возобновление;
- запуск и закрытие Epic War;
- скриншот выбранного MuMu прямо в Android-приложении;
- последние действия/история;
- сопряжение по шестизначному коду;
- API-токен хранится только после сопряжения.

## 1. Подключить сервер к MuMu Bot

Скопируй папку `pc-server` рядом с текущей сборкой или скачай два файла:

- `remote_server.py`
- `install_into_mumubot.py`

Запусти:

```bat
python install_into_mumubot.py "C:\путь\к\MuMuBot"
```

Установщик:
1. скопирует `remote_server.py` в папку бота;
2. сделает `main_before_remote.py`;
3. добавит запуск сервера в `main.py`;
4. добавит проверку удалённой паузы перед задачами.

После запуска MuMu Bot рядом появится файл **REMOTE_PAIRING.txt**. В нём адрес сервера и код сопряжения.

Windows Firewall при первом запуске Python может спросить доступ к сети — разреши для частной сети.

## 2. Android

Открой папку `mumu-remote-control` как отдельный проект Android Studio.

Приложение: `ru.sedoysadist.mumuremote`

Минимальная версия Android: 8.0 (API 26).

### Сопряжение

На первом экране:

1. укажи адрес ПК, например `http://192.168.1.50:8765`;
2. введи шестизначный код из `REMOTE_PAIRING.txt`;
3. нажми **Сопрячь**.

После этого токен сохранится на телефоне.

## Доступ не только дома

Сам сервер находится **только на твоём ПК**, отдельного хостинга нет.

Для доступа из другого конца города самый безопасный простой вариант — Tailscale на ПК и телефоне. Тогда в приложении указываешь Tailscale-IP ПК вида:

`http://100.x.x.x:8765`

Не нужно открывать порт на роутере, а трафик между телефоном и ПК зашифрован.

**Не советую** просто пробрасывать порт 8765 в интернет: первая версия API использует HTTP, потому что рассчитана на локальную сеть или защищённую mesh-сеть.

## API

- `POST /api/v1/pair`
- `GET /api/v1/accounts`
- `POST /api/v1/accounts/{device}/pause`
- `POST /api/v1/accounts/{device}/resume`
- `POST /api/v1/accounts/{device}/game/start`
- `POST /api/v1/accounts/{device}/game/stop`
- `GET /api/v1/accounts/{device}/screenshot`
- `GET /api/v1/accounts/{device}/history`
